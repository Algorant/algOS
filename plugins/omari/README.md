# omari

overview and window switching on omarchy's scrolling layout.

## files

- [the exported plugin](https://github.com/Algorant/dotfiles/tree/main/home/.config/omarchy/plugins/bergdahlchi.omari): its overview, alt-tab view, helper scripts and hyprland lua overlays belong together.
- [my omari settings](https://github.com/Algorant/dotfiles/tree/main/home/.config/omari): `keybinds.conf` and `settings.conf` are separate from the plugin directory.
- my overview key is `SUPER + TAB`; that is not the upstream default.
- the plugin needs omarchy's quickshell modules and a compatible hyprland lua/scrolling setup. enabling it installs toggle overlays, so review those changes before borrowing it.

[upstream](https://github.com/chicreativetech/omari).
